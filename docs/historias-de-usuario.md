# Histórias do Usuário

1. Como visitante, quero me cadastrar e fazer login para acessar o sistema.
2. Como cliente, quero cadastrar meus dados (RG, CPF, nome, endereço, profissão e até 3 rendimentos) para poder alugar um carro.
3. Como cliente, quero criar um pedido de aluguel de um automóvel para contratar o serviço.
4. Como cliente, quero consultar o status do meu pedido para acompanhar a análise.
5. Como cliente, quero cancelar um pedido que ainda não foi aprovado.
6. Como agente, quero cadastrar automóveis para disponibilizá-los para aluguel.
7. Como agente, quero aprovar ou rejeitar pedidos após a análise financeira.
